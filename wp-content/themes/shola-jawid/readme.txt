A bilingual-ready, Persian-active WordPress theme for شعله جاوید (Shola
Jawid), a Persian-language editorial publishing platform. A faithful,
pixel-accurate conversion of the v6 "Quiet Press" static prototype — see
the companion `shola-core` plugin for the content model (custom post
types, taxonomies, meta fields).

== Description ==

Shola Jawid is built for a Persian (RTL) editorial publication covering
articles, issues (PDF publications), and library documents. Design and
markup are a pixel-accurate port of the finished v6 static prototype; no
visual redesign was performed during conversion.

== Installation ==

1. Install and activate the `shola-core` plugin first (owns the content
   model — the theme degrades gracefully, but does not fatal, if it's
   inactive).
2. Install and activate this theme.
3. Assign menus under Appearance → Menus.
